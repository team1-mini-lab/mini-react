# 사람 판정 — 영역 C (Hermes · gemini-3-flash-preview)

판정 칸은 Claude 제안으로 채워 두었다. **PR 리뷰에서 사람이 승인(또는 수정)하면 확정**된다. 판정 칸에 **진짜 반례 / 기존 한계 / 아님** 중 하나를 적는다. "Claude 의견"은 참고용이며 판정이 아니다.

> 공통 주의: 이 결과는 무료 등급 한도(429) 속에서 나와 파일을 제대로 읽지 못한 흔적이 있다. 우리 설계에 없는 이름(`REMOVE`/`INSERT`, `history.dom`, `data-path`, "SRS 1.1-C")을 근거로 든다.
